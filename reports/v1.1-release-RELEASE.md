# Superbot v1.1.0 — 开关、项目交接、上下文经济

## 新增
- **每项目 handoff**：项目根 `SUPERBOT-HANDOFF.md`，由账本自动投影（目标/进行中/待决策/返工/验收命令/约束/下一步），<4.5KB，不写聊天记录；事件后 400ms 防抖刷新。
- **Manager 工具** `superbot_project_handoff`：按项目生成/预览交接文件；拒绝覆盖非 Superbot 文件。
- **上下文纪律**：worker brief 增加「先读项目 handoff」；manager 系统提示要求用 handoff/overview 恢复上下文，不回放历史。
- **开关契约**：桌面 App 自带 CLI `plugin --profile desktop remove dsh-superbot` 会同时移除依赖和 bundle；关闭后插件代码不加载，原项目/会话/账本保留，普通模式可读 handoff 继续。
- 配置：`projectHandoff`（默认 true）、`handoffFile`（默认 `SUPERBOT-HANDOFF.md`）。
- 文档：`docs/HANDOFF-AND-TOGGLE.md`。

## 验证
- 154 + 18 = 172 tests PASS。
- 桌面 profile 安装/卸载实测：`plugin add` 自动登记 bundle，`plugin remove` 自动移除依赖与 bundle。
- 打包自包含（vendored task-engine）。
