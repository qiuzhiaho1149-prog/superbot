# Superbot v1.3.0 — 首次接入项目地图 / Harness / 多 Session 规划

## 新增
- `superbot_project_profile`：只读项目侦察（技术栈、构建/测试命令、顶层结构、AGENTS/CI/handoff 缺口）；可写 `SUPERBOT-PROJECT.md`，拒绝覆盖非生成文件。
- 首次接入确认后自动为每个项目生成 `SUPERBOT-PROJECT.md` + `SUPERBOT-HANDOFF.md`（项目地图与交接）。
- Manager prompt：新项目先 profile→补 handoff/harness→再规划实现；多 session 用任务 DAG（一个 task = 一个 session 合约；同项目一个写者；只读 recon/verifier 可并行），禁止并发写同一项目。
- 文档 `docs/PROJECT-BOOTSTRAP-AND-WORKSTREAMS.md`。
- 不自动改写 AGENTS.md/CI/package.json；harness 缺口只作为小步任务提案，需人类确认。
