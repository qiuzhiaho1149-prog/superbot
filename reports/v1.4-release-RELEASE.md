# Superbot v1.4.0 — 单窗口管理与会话内授权

## 新增
- 单窗口运行模型：`docs/ONE-WINDOW-OPERATIONS.md`；Manager 每次汇报 1 行总览 + 只列需老板动作项；面板仅在需要证据原文/因果时间线/批量核对时使用。
- **会话内退回**：新增 `superbot_task_reject`，与 `superbot_task_accept` 一样走宿主 approval（Agent 不能自己点允许）；老板说“退回”即可在会话里完成人工退回，不必开面板。
- Manager prompt：单窗口汇报格式、待决定项的证据数/建议动作、何时让老板打开面板。
- 自包含桌面安装器 `install-desktop.sh` 更新到 v1.4.0。

## 验证
- 162 + 18 = 180 tests PASS（含人工退回 approval 路径测试）。
