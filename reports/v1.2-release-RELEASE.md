# Superbot v1.2.0 — 口语需求路由与自动改写

## 新增
- **目标路由纪律**（Manager prompt）：先判断项目再派工；用户明确项目名→直接路由；不明确→`superbot_project_match`；`needsConfirmation=false` 才自动选 top1，否则只问一个阻塞问题；跨项目目标拆成每项目一个 requirement/plan；session 只是执行资源，不是路由目标。
- **口语需求自动改写**：原话逐字进 `requirement.text`；L0/L1/L2/L3/L4 改写进 spec/tasks；模糊词转可观察验收或给 2–3 个选项；最多 3 个阻塞问题；改写后 3 行确认。
- 文档 `docs/INTENT-ROUTING.md`；新增 4 个路由单元测试（明确项目/无信号/近分/泛化句）。
- 不新增提示词评分器/哈希校验层；沿用现有 match + 账本验收证据。

- 路由决策：`needsConfirmation = 无候选 || top<4 || 与第二名差<2`。
