# 桌面 App 安装步骤（0.2.x，待用户执行/验证）

> 当前状态：**NOT RUN**。为避免改动你的桌面 profile，本步需要你同意后执行。
> 已验证：桌面 App 内核 0.2.2-rc.1 与插件 core 兼容（见 `reports/install-history-test-2026-11-08/evidence/dsh-0.2.2-smoke.txt`）。

1. 关闭 DeepSeek Harness 桌面 App。
2. 找到桌面 profile 目录（macOS）：`~/Library/Application Support/DeepSeek Harness/profiles/web/package.json`（若不存在，先在 App 里打开一次插件设置以生成 profile）。
3. 备份该文件。
4. 在 `dependencies` 中加：
   ```json
   "dsh-superbot": "link:/Users/afraxx/Documents/DeepSeekProjects/superbot-next/packages/dsh-superbot"
   ```
5. 在 `dsh.profile.bundles` 中加：`"dsh-superbot"`。
6. 重新打开桌面 App，进入 Superbot 面板；首次会要求“首次接入盘点”。
7. 自检：
   - 面板能打开（任务/地图/历史/验收）；
   - `Settings → Plugins` 能看到 dsh-superbot；
   - 新建会话选「Superbot · manager」，让它调用 `superbot_fleet_status` 能返回项目/线程数。
8. 如需回滚：恢复第 3 步备份并重启 App。

若桌面 App 不允许 link 本地包：先用 `npm pack` 生成 `dsh-superbot-0.1.0.tgz`，用 `file:` 依赖替换 link。
