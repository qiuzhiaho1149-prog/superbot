# 桌面 App 安装步骤（macOS）

Superbot v1.0.0 支持通过桌面 App 自带的 CLI 安装到 `desktop` profile。
> 已验证：桌面 App 自带 CLI 版本 0.2.2-rc.1；`dsh plugin --profile desktop add` 可安装并自动登记 bundle；插件 server 入口可从 desktop profile 正常 import。
> 未验证：本机实际重启 App 后的 UI（为避免中断当前会话未执行）；如果失败，按第 6 步回滚。

## 1. 准备
1. **完全退出** DeepSeek Harness（Cmd+Q），确认进程已退出。
2. 桌面 App 自带 CLI 路径：
   `/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh`
   自检：`"$CLI" --version` 应输出 `0.2.2-rc.1`。
3. 备份 profile：
   ```bash
   PROFILE_DIR="$HOME/.dsh/profiles/desktop"
   cp "$PROFILE_DIR/package.json" "$PROFILE_DIR/package.json.bak.$(date +%s)"
   cp "$PROFILE_DIR/pnpm-lock.yaml" "$PROFILE_DIR/pnpm-lock.yaml.bak.$(date +%s)" 2>/dev/null || true
   ```
   如果 `$PROFILE_DIR` 不存在：先打开一次 App 再退出，让它生成 desktop profile。

## 2. 下载与校验
```bash
curl -L -o ~/Downloads/dsh-superbot-1.2.0.tgz \
  "https://github.com/qiuzhiaho1149-prog/superbot/releases/download/v1.2.0/dsh-superbot-1.2.0.tgz"
curl -L -o ~/Downloads/dsh-superbot-SHA256SUMS \
  "https://github.com/qiuzhiaho1149-prog/superbot/releases/download/v1.2.0/SHA256SUMS"
cd ~/Downloads && shasum -a 256 dsh-superbot-1.2.0.tgz
# 与 SHA256SUMS 中对应值一致
```
**不要删除 tarball**：profile 里会记录 `file:` 依赖路径。

## 3. 安装到 desktop profile
```bash
CLI="/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"
"$CLI" plugin --profile desktop add ~/Downloads/dsh-superbot-1.2.0.tgz
```
成功的标志：
- 输出 `+ dsh-superbot 1.0.0`；
- `~/.dsh/profiles/desktop/package.json` 的 `dsh.profile.bundles` 自动包含 `dsh-superbot`（该 CLI 会自动登记）。

## 4. 重启并验收
1. 打开 DeepSeek Harness。
2. 侧栏应出现「Superbot」→ 打开面板。
3. 首次接入：面板会扫描项目/线程，**由你本人确认**盘点结果（插件不会自动确认）。
4. 能打开「任务 / 地图 / 历史」页即安装成功。

## 5. 失败时
- 面板不出现 / App 启不来：完全退出 App，执行第 6 步回滚，把 `package.json.bak.*`、启动日志、App 版本发给维护者。
- 不要反复重装或删除 `~/.dsh` 其它文件。

## 6. 回滚（安全）
```bash
# 先完全退出 App
cd ~/.dsh/profiles/desktop
LATEST_PKG=$(ls -t package.json.bak.* | head -1)
LATEST_LOCK=$(ls -t pnpm-lock.yaml.bak.* | head -1 2>/dev/null || true)
cp "$LATEST_PKG" package.json
[ -n "$LATEST_LOCK" ] && cp "$LATEST_LOCK" pnpm-lock.yaml
rm -rf node_modules/dsh-superbot
# 重新打开 App
```
如果仍异常：恢复整个 profile 目录备份（安装前如已整目录备份），或联系维护者，不要删除 `storages/` 账本与历史会话。
