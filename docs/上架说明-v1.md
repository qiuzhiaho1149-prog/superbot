# Superbot · 上架说明（面向购买者的产品页文案）

**一句话**：Superbot 是你 DSH 里的「核心调度员工」——你只和它对话，它把需求拆成任务、派给 worker 执行、自动审计证据、只把「需要你拍板」的事交回给你。

## 为什么值 99 元

- 你只需要**一个对话窗口**：说人话下需求，不用填任务字段、不用管线程。
- 它替你管**所有项目和线程**：一个会话调度所有 worker/verifier 子线程，账本实时记录谁在做什么。
- **自动审计，防 Agent 自夸**：worker 的自我报告不算数；verifier 在一次性工作副本里真实执行验收命令，证据（exitCode/指纹/沙箱模式）进账本；只有低风险且证据齐的任务才自动通过，其余必须你点验收。
- **看得见全局**：结果导向任务板（需你决定/返工/审计中/执行中/已完成）+ 线程甘特地图（每条线程在哪、跑了多久、点开原会话）+ 历史工作接管（装进你用了几个月的 DSH，旧线程摘要一键导入/交给 Superbot 分析）。
- **不丢任务**：失败自动返工、卡住 30 分钟标记「疑似卡住」、可取消、可退回。

## 装进已有 DSH（核心场景）

1. 安装后先做「首次接入盘点」：Superbot 只读扫描你全部项目和线程，把「进行中/挂起/归档」建议清单给你确认，不碰你的历史会话。
2. 历史工作：面板「历史」里能看到每条旧线程的意图摘要，可勾选「导入为历史工作项」（只读调查+人工验收，绝不自动改历史），或逐条「交给 Superbot 分析」。
3. 确认后，你只需在「Superbot 对话」里说需求，其余交它。

## 安全边界（默认）

- Manager 无 shell/只读；worker 写项目；verifier 只读+受控执行；人工验收默认走宿主 approval 弹窗（面板直连默认关闭）。
- 验收命令固定白名单（node --test/npm test/pytest/cargo test…），禁止任意 shell。
- 账本单实例锁、工作区指纹、沙箱模式证据链。

## 安装（桌面 App，一条命令）

1. 完全退出 DeepSeek Harness（Cmd+Q）。
2. 终端执行：
   ```bash
   curl -fL -o /tmp/superbot-install.sh \
     "https://github.com/qiuzhiaho1149-prog/superbot/releases/download/v1.4.0/install-desktop.sh"
   sh /tmp/superbot-install.sh
   ```
3. 重开 App → 侧栏「Superbot」→「首次接入盘点」。

- 插件**零第三方依赖**（task-engine 已内置），安装器不运行 npm/pnpm，不会改动其他插件依赖。
- 兼容 macOS 桌面 App（DSH 0.2.x）与 DSH CLI 0.2.1-rc.5 / core 0.2.2-rc.1。
- 详细排错：`docs/INSTALL.md`。
